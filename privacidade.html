Política de privacidade — GICMO-rclone

Esta política descreve como o GICMO-rclone utiliza dados autorizados do Google Drive para backups e transferências de arquivos de pesquisa.

Última atualização: 13 de outubro de 2026

O GICMO-rclone não é um produto público de armazenamento: é uma configuração de cliente OAuth para uso restrito com a ferramenta de código aberto rclone. O acesso requer autorização expressa do titular da conta Google.

1. Responsável e contato

O aplicativo é administrado pelo responsável técnico do projeto GICMO. Dúvidas, pedidos sobre dados ou solicitações relacionadas a esta política podem ser encaminhadas ao seguinte contato:

E-mail de contato: fredson.silva@prof.saocamilo-sp.br

2. Finalidade do acesso

O aplicativo permite autenticar o rclone na API do Google Drive para enviar backups de arquivos científicos, conferir a integridade das cópias e recuperar arquivos quando necessário. Não utiliza o Google Drive para publicidade, criação de perfis ou venda de dados.

3. Dados acessados

Dependendo do escopo aprovado na tela de consentimento do Google, podem ser acessados: (a) arquivos selecionados para backup ou recuperação; (b) seus nomes, identificadores, tamanhos, datas e hashes quando disponibilizados; e (c) tokens OAuth necessários para autenticação. Procuramos configurar a autorização com o menor escopo suficiente para a finalidade descrita.

4. Como os dados são usados

O rclone usa os dados exclusivamente para transferir, listar, comparar e restaurar arquivos indicados pelo operador. O conteúdo das pesquisas não é processado por este site nem publicado automaticamente. Operações de remoção ou atualização no Drive dependem dos comandos efetivamente executados pelo responsável.

5. Armazenamento e segurança

Os arquivos de pesquisa permanecem nos sistemas escolhidos pelo responsável, como Google Drive, computador de trabalho e ambientes temporários de computação. Os tokens de autenticação ficam na configuração operacional do rclone nos dispositivos ou instâncias autorizados, e não fazem parte do código publicado no GitHub Pages. Seu acesso deve ser limitado por permissões locais e práticas de gestão de segredos.

6. Terceiros e compartilhamento

A execução depende de serviços de infraestrutura, conforme o fluxo configurado: Google Drive (armazenamento), provedores de computação eventualmente utilizados para as simulações e GitHub Pages (hospedagem deste site informativo). Dados podem transitar por esses provedores para execução das tarefas autorizadas. Não vendemos dados nem os fornecemos a anunciantes.

7. Retenção e exclusão

Os arquivos de backup são mantidos conforme a necessidade científica e a capacidade de armazenamento definida pelo responsável. O titular da conta pode excluir os arquivos no Google Drive. A revogação da autorização OAuth impede novos acessos com aquela autorização, mas não apaga automaticamente os backups já existentes nem cópias previamente realizadas.

8. Revogação da autorização

O titular pode revogar o acesso do aplicativo nas configurações de conexões de terceiros da Conta Google. Também é possível remover os tokens armazenados localmente na configuração do rclone. Para dúvidas, utilize o contato acima.

9. Privacidade deste site

Este site é composto de páginas estáticas e não implementa formulários, contas de usuário, scripts de análise de tráfego ou cookies próprios. A plataforma de hospedagem GitHub Pages pode processar informações técnicas de acesso de acordo com suas políticas. Links para serviços externos estão sujeitos às políticas desses serviços.

10. Alterações desta política

O conteúdo poderá ser atualizado se os procedimentos de backup, escopos de autorização ou provedores envolvidos mudarem. A data da última atualização será indicada nesta página.
